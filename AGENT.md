# AGENT.md --- SRS Material Handling Website Design & Build Guide

## 1. PROJECT OVERVIEW

You are designing a premium, modern, human-made single-page website for:

**SRS Material Handling India Pvt Ltd / Sri Ram & Service**
Chennai-based material handling equipment, forklift service, spare
parts, and industrial solutions company.

The website must NOT look like: - an AI-generated landing page - a
generic SaaS template - a startup dashboard - a copied version of the
old SRS website - a generic industrial template with stock imagery

The goal is to make the website feel intentionally designed specifically
for SRS, using: - SRS's real brand identity - real equipment
photography - real company information - technical details - strong
industrial visual hierarchy - clear business-oriented conversion paths

The design should feel premium, trustworthy, technically competent, and
established.

# 22. TYPOGRAPHY

The current geometric oversized typography can contribute to the AI/SaaS
appearance.

Prefer a professional industrial typeface.

Possible choices: - IBM Plex Sans - DIN-style typeface - Inter - Manrope

Priority: 1. readability 2. technical credibility 3. strong hierarchy 4.
restrained character

Do not use: - overly futuristic fonts - rounded startup fonts -
decorative fonts - excessive giant text everywhere

### Heading hierarchy

H1: Large and strong, but not absurdly oversized.

H2: Strong section headline.

H3: Functional category/product title.

Body: Comfortable reading width.

Technical metadata: Small uppercase labels with letter spacing.

# 28. ANIMATION

Animations should be subtle.

Good: - smooth section reveal - image parallax used sparingly - subtle
image scale on hover - button arrow movement - sticky header
transition - smooth anchor scrolling

Avoid: - excessive scroll animations - spinning equipment - large text
flying around - excessive 3D motion - distracting loaders - animation on
every element

Animation should support hierarchy, not demonstrate technology.
